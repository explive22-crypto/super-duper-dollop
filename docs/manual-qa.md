# Manual QA

## Scope

Ручная проверка браузерного трекера задач в папке `app/`.

Проверяются только текущие возможности MVP: добавление, отметка выполнения, удаление, фильтры, счётчик, сохранение и устойчивость к повреждённому `localStorage`.
