# Roadmap

## Текущий этап

Проект находится на этапе учебного MVP: есть рабочий браузерный трекер задач без сборщика и зависимостей. Текущий фокус — стабилизировать основу проекта, описать процесс развития и сделать прогресс измеримым.

## MVP baseline

MVP считается базово собранным, потому что приложение уже умеет:

- добавлять задачи;
- отмечать задачи выполненными;
- удалять задачи;
- фильтровать список;
- показывать счётчик прогресса;
- сохранять задачи в `localStorage`;
- показывать пустое состояние.

## Блок 1: стабилизация

Цель блока — снизить базовые runtime-риски и добавить проектный контур управления.

- защитить чтение `localStorage` от повреждённых данных;
- заменить простой `Date.now()` id на более устойчивый генератор;
- обновить `docs/idea.md`;
- добавить roadmap;
- добавить project status;
- добавить manual QA template;
- добавить project memory.

## Блок 2: проверки и качество

Цель блока — сделать качество проекта проверяемым.

- добавить минимальную автоматическую проверку JavaScript, если окружение позволяет;
- описать ручной QA-прогон после изменений;
- проверить приложение в браузере;
- зафиксировать найденные дефекты и решения;
- уточнить критерии готовности MVP.

## Блок 3: улучшение UI/UX

Цель блока — сделать интерфейс понятнее и удобнее без усложнения архитектуры.

- улучшить состояние пустого списка для разных фильтров;
- добавить доступные подписи для формы и кнопок;
- проверить адаптивность на узком экране;
- сделать визуальные состояния кнопок и задач последовательными.

## Блок 4: расширение трекера

Цель блока — добавлять новые продуктовые возможности только после стабилизации основы.

- редактирование текста задачи;
- даты или сроки;
- категории или теги;
- экспорт и импорт задач;
- простая статистика.

## Anti-scope

Пока не входит в roadmap:

- React, Vite, Flutter или другой фреймворк;
- сборщик;
- серверная часть;
- база данных;
- авторизация;
- GitHub Actions;
- npm-зависимости.
