# Project Memory

## Purpose

Этот файл хранит локальную память проекта `super-duper-dollop`: факты, решения, открытые вопросы и следующий шаг. Он нужен, чтобы следующие Codex-блоки продолжали работу последовательно.

## Current facts

- Проект уже существует в репозитории `explive22-crypto/super-duper-dollop`.
- Это простой браузерный HTML/CSS/JS-трекер задач.
- Основное приложение находится в папке `app/`.
- Документация находится в папке `docs/`.
- Текущий фокус: стабилизация, roadmap, status tracking и manual QA.
- `ai-project-memory` и `konstitutsiya` не трогаются в этом блоке.

## Decisions

- Не добавлять npm, package.json, сборщик или фреймворк.
- Не превращать проект в React, Vite, Flutter или серверное приложение.
- Вести развитие через отдельные Codex-блоки.
- Любой следующий изменяющий блок должен иметь ограниченный scope и явную проверку.
- Project memory для этого проекта пока хранится локально в `docs/project-memory.md`.
