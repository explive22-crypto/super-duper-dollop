# Идея приложения-трекера

## Краткое описание

`super-duper-dollop` — это простой учебный трекер задач для начинающего разработчика.

Пользователь может записывать небольшие дела, отмечать выполненное и видеть свой прогресс. Проект помогает потренировать базовые навыки: структуру файлов, работу с интерфейсом, состояние данных и простые пользовательские действия.

## Основные сценарии

- пользователь открывает приложение и видит список задач;
- пользователь добавляет новую задачу;
- пользователь отмечает задачу как выполненную;
- пользователь удаляет ненужную задачу;
- пользователь переключает фильтры задач;
- приложение сохраняет задачи в браузере.

## Что уже реализовано

- поле ввода задачи;
- кнопка добавления;
- список задач;
- отметка выполнения через чекбокс;
- удаление задачи;
- фильтры `Все`, `Активные`, `Выполненные`;
- счётчик `Выполнено: X из Y`;
- сохранение задач в `localStorage`;
- пустое состояние `Задач пока нет`;
- базовая защита от повреждённых данных в `localStorage`.

## Ближайший roadmap

- вести статус проекта и прогресс по блокам;
- фиксировать ручную проверку в `docs/manual-qa.md`;
- поддерживать проектную память в `docs/project-memory.md`;
- добавить простые автоматические проверки, если окружение позволит;
- улучшить доступность и небольшие детали интерфейса.

## Что можно добавить позже

- даты выполнения;
- категории или теги;
- редактирование текста задачи;
- статистику за день или неделю;
- экспорт и импорт задач;
- более аккуратный визуальный дизайн.

## Учебная цель

Главная цель проекта — не собрать сложный продукт, а пройти понятный путь от пустой папки до работающего маленького приложения с документацией, проверками и планом развития.
